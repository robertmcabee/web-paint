# web-paint

This is a MSPaint-like web painting tool built with React.

## Installation

1. Clone this repo
2. `cd web-paint`
3. `npm install`
4. `npm run dev`

Then, go to http://localhost:5173

## Features

MVP Features

- canvas
- pencil
- color picker
- eraser

Nice to Have

- undo/redo
- color picker
- brush size
- stencils
- shapes
- fill bucket
- adjustable canvas size
